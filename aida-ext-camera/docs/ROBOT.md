# Шаг 3: робот на карте

Открыть **http://localhost:8080/robot.html**, полноэкранная карта — **/map.html**.
Нужны результаты шагов 1 и 2. Камера и её настройки должны остаться прежними.

## Установка

Доска AprilGrid 3 × 3 (та же, что для пола) закрепляется на роботе **горизонтально,
рисунком вверх**. Вторую такую же доску с пола уберите: ID маркеров совпадают.

## Калибровка

1. **Высота доски** — расстояние от пола до рисунка. Камера показывает свою оценку
   по полной 3D-позе доски («Взять оценку камеры»); лучше сверить её рулеткой.
2. **Центр робота** — «Начать запись вращения», медленно развернуть робота на месте
   (минимум 90°, лучше полный оборот), «Закончить». Центр вращения становится
   точкой робота на карте.
3. **Направление «вперёд»** — «Начать запись движения», проехать прямо ≥ 0,5 м,
   «Закончить». Без этого шага «вперёд» — ось X доски.

Результат хранится в `data/robot/current.json`; новая привязка пола его не сбрасывает.

## Как считается поза

Доска лежит параллельно полу на известной высоте, поэтому у неё три неизвестных:
x, y и курс. Лучи из камеры через углы маркеров пересекаются с плоскостью
`z = высота`, жёсткое 2D-совмещение даёт начальную позу, затем она уточняется
по ошибке перепроецирования. Маркеры, не согласующиеся с остальными, отбрасываются.

Параллельно каждый кадр считается полная 3D-поза доски (PnP): из неё берутся
показания «Высота Z» и «Наклон». Если доска явно не на заданной высоте или
наклонена больше 4°, на карту выводится 3D-поза (робот рисуется янтарным пунктиром),
а такие кадры не участвуют в калибровке центра и направления.

Робот: `позиция = позиция доски + R(курс доски) · offset_m`,
`курс = курс доски + heading_offset_rad`.

## API

| Запрос | Что возвращает |
|---|---|
| `GET /api/robot/pose` | последняя поза: `robot` (`x_m`, `y_m`, `yaw_rad`, `z_m`, `tilt_deg`, `std_xy_m`, `rms_px`, `source`), `time` |
| `GET /api/robot/events` | поток поз (Server-Sent Events), событие на каждое измерение |
| `GET /api/robot/state` | калибровка, оценка высоты, текущее наблюдение |
| `GET /api/robot/export` | калибровка робота и пола одним JSON |

Координаты в метрах, углы в радианах, система координат пола шага 2.
`robot` равен `null`, когда доска не видна. `source`: `board_plane` — точная поза
на заданной высоте, `free_6dof` — приблизительная.

## Проверки

`tests/test_robot.py`: восстановление позы и высоты по синтетическим наблюдениям,
отбрасывание неверно прочитанного маркера, центр вращения и направление движения,
переход на 3D-позу, когда доска не на своей высоте.
