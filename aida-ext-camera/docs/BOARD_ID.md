# Определение калибровочной доски

Программа сравнивает стандартные словари ArUco и четыре семейства AprilTag,
доступные в OpenCV. Проверяет исходный и зеркальный снимки в масштабах 1, 2, 4.
Исправление ошибок отключено, чтобы уменьшить число случайных совпадений.
Нестандартные словари и новые семейства AprilTag вне OpenCV не проверяются.

## Запуск в Docker

```sh
docker build -t ext-cam-board-id .
docker run --rm --user "$(id -u):$(id -g)" \
  -v "$PWD:/work" -w /work \
  ext-cam-board-id "image copy.png"
```

Результаты: `board_identification.json` с ID и координатами углов и
`board_identification.png` с отмеченными маркерами лучшего кандидата.
Единичное совпадение не является достаточным основанием для определения.
Скрипт проверяет рамку толщиной 1, 2 и 3 ячейки и сохраняет лучший отдельный
масштаб для каждой комбинации словаря, рамки и зеркальности;
результаты разных масштабов не суммируются.

## Результат для предоставленного снимка

Подтверждено семейство **AprilTag tag36h11**, чёрная рамка **2 ячейки**.
Первоначальная проверка с рамкой 1 прочитала только 27 маркеров; это была
неверная настройка. Исправленный детектор на исходном фото проверяет более 80
маркеров, на одном из сохранённых кадров Jabra — все 88.
На фото видна сетка 11 × 8. Обновлённый идентификатор с рамкой 2 и масштабом 4
прочитал все 88 ID от 0 до 87 на исходном снимке.

Размеры нельзя измерить в миллиметрах по одному фото без масштаба.
Используйте исходный макет и проверьте размеры реальной доски линейкой.

Для привязки камеры к полу доска подходит: нужны параметры камеры,
известные координаты углов доски и её положение в системе рабочей зоны.
Для определения преобразования «маркер → робот» одной доски недостаточно:
нужно измерить монтаж или знать положение корпуса робота в контрольных позах.
