# Шаг 1: intrinsics камеры

Локальный веб-интерфейс для AprilGrid **tag36h11, 11 × 8**, как на предоставленном
снимке. Python, OpenCV и веб-сервер запускаются в Docker. Браузер получает
изображение от сервера; разрешение на камеру браузера не требуется.

## Запуск

```sh
./run.sh
```

Откройте **http://localhost:8080**. По умолчанию контейнер получает только внешнюю
**Jabra PanaCast 20** через её постоянный `/dev/v4l/by-id/...video-index0`.
Встроенная Chicony не передаётся контейнеру.

Скрипт использует Docker builder `default`: выбранный на этом компьютере
`jbuilder` не смог разрешить адрес Docker Hub. Builder можно переопределить
переменной `CALIBRATION_BUILDER`.

Для другой USB-камеры сначала найдите её постоянный путь:

```sh
ls -l /dev/v4l/by-id/
USB_CAMERA_DEVICE=/dev/v4l/by-id/usb-YOUR_CAMERA-video-index0 \
USB_CAMERA_NAME="Моя USB-камера" ./run.sh
```

Встроенная камера ноутбука тоже может называться USB: выбирайте по имени устройства,
а не по одному наличию `usb` в пути. Нужен узел видеопотока, обычно `video-index0`.

## Как откалибровать

1. Установите камеру и задайте рабочее разрешение; обычно 1920 × 1080.
2. Для Jabra отключите **Intelligent Zoom** в Jabra Direct → Settings → Camera.
   Эта функция автоматически меняет кадрирование; стандартные V4L2-контролы
   не позволяют приложению надёжно проверить её состояние.
   [Инструкция производителя](https://www.jabra.com/supportpages/jabra-panacast-20).
3. Зафиксируйте фокус, зум и поле зрения. Сохраните эти настройки для дальнейшей работы.
4. Измерьте сторону чёрного квадрата и белый промежуток между соседними квадратами.
   Значения 25 и 7,5 мм в форме — начальные; проверьте свою распечатку.
   Доска должна быть жёсткой и плоской. Подтвердите параметры и нажмите «Применить».
   Для этой доски толщина чёрной рамки — **2 ячейки** (пункт «Раскладка маркеров»).
   Стандартная настройка 1 даёт уменьшенные и неверные контуры.
5. Подключите камеру. Найденные маркеры подсветятся зелёным. Держите доску
   неподвижно, нажмите «Сохранить кадр» или пробел. Есть автосбор раз в 3 секунды.
6. Наберите 25–35 разных наблюдений: центр, края, углы, разные расстояния и наклоны
   по двум осям. Для сохранения нужны ≥8 маркеров в ≥2 рядах и ≥3 столбцах;
   слишком маленькие, размытые и почти одинаковые наблюдения не принимаются.
7. Нажмите «Рассчитать intrinsics». Минимум — 12 кадров. Проверьте RMS, предупреждения
   и ошибки отдельных кадров. Плохие кадры можно исключить и повторить расчёт.
8. Скачайте JSON или OpenCV YAML. Переключатель «Исправить искажения» показывает
   результат на живом изображении; исходные наблюдения всегда остаются неисправленными.

Используется обычная pinhole-модель OpenCV с коэффициентами `k1,k2,p1,p2,k3`.
Низкий RMS не заменяет проверку на независимых кадрах. Для fisheye-объектива
потребуется другая модель; в этом интерфейсе она не реализована.

## Файлы и сессии

- `data/current.json` — активная сессия, восстанавливается после перезапуска.
- `data/sessions/<id>/` — исходные PNG, миниатюры, геометрия наблюдений и результаты.
- `intrinsics.json` — матрица, дисторсия, разрешение, настройки камеры, RMS по кадрам.
- `intrinsics.yaml` — матрица и дисторсия в формате OpenCV FileStorage.

«Новая сессия» сохраняет предыдущие файлы на диске. Изменение разрешения,
геометрии доски или USB-камеры требует новой сессии. Изменения доступных через
V4L2 настроек фокуса/зума/кадрирования между сохранениями проверяются.
AI-кадрирование производителя необходимо отключать отдельно.

После обновления детектора старые сохранённые PNG автоматически перераспознаются.
Предыдущая геометрия и результат остаются в `session_before_detector_v2.json`;
калибровку нужно рассчитать заново по исправленным углам. Проверка углов использует
четыре измеренные границы маркера и повторное чтение кода. Подгонки углов к идеальной
сетке доски нет.

```sh
docker compose stop       # остановить приложение
docker compose logs -f    # журнал
```

## Проверки в Docker

```sh
docker build --builder default -f tests/Dockerfile -t ext-cam-qa .
docker run --rm -v "$PWD:/work" ext-cam-qa
docker run --rm --network host -v "$PWD:/work" ext-cam-qa python tests/browser_check.py
```

Второй тест требует запущенного приложения с Jabra. Он кратковременно подключает
камеру и проверяет видеопоток. Не запускайте его во время своей съёмки.
Проверки API используют отдельную временную сессию и синтетические наблюдения.
